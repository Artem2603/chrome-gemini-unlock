# Chrome Gemini Unlock

[![test](https://github.com/artem2603/chrome-gemini-unlock/actions/workflows/test.yml/badge.svg)](https://github.com/artem2603/chrome-gemini-unlock/actions/workflows/test.yml)

[English](README.md) · **Русский** · [Français](README.fr.md) · [Deutsch](README.de.md)

Скрипт для Windows, который включает в Google Chrome боковую панель Gemini (внутреннее название «Glic»), а при желании и её агентские функции, когда Chrome прячет их из-за языка профиля или региона.

> Неофициальный проект, не связан с Google. Флаги экспериментальные: Google может переименовать или убрать их в любой версии Chrome и всё равно может ограничивать доступ по аккаунту. Используйте на свой риск.

## Что делает скрипт

0. Ищет Google Chrome: в реестре, среди запущенных программ и в стандартных папках. Если Chrome не установлен или ни разу не запускался под этой учётной записью Windows, скрипт останавливается и ничего не меняет.
1. Закрывает Google Chrome. Если Chrome запущен, скрипт сначала спрашивает разрешения (`-Force` пропускает вопрос). В неинтерактивном сеансе, где спросить нельзя, скрипт останавливается, ничего не меняя, и просит запустить его с `-Force`. Затем он просит закрыться каждое окно, как если бы вы закрыли их сами, а то, что продолжает работать, через несколько секунд завершает принудительно. В этом случае при следующем запуске Chrome может предложить восстановить страницы: нажмите **«Восстановить»** (Restore). Текст в неотправленных формах пропадёт в любом случае.
2. Включает в файле Chrome `Local State` 5 флагов Glic для боковой панели, её кнопки на панели инструментов и пункта в контекстном меню:
   `glic`, `glic-toolbar-height-side-panel`, `glic-horizontal-tab-toolbar-button`, `glic-toolbar-button-location`, `glic-context-menu-below-search`.

   Ещё 6 агентских флагов включаются только с `-Agent`; запуск без `-Agent` возвращает их в Default:
   `glic-actor`, `enable-browser-actuator-for-glic-experimental-triggering`, `glic-background-actuation`, `glic-actor-autofill`, `glic-actor-cursor`, `glic-actor-script-tools`.

   Если установленный Chrome новее версии, после которой истекает срок одного из включаемых флагов, скрипт предупреждает, что Chrome может этот флаг игнорировать.
3. Переключает интерфейс Chrome на английский (en-US) и ставит языки всех профилей `en-US,en`.
4. Заставляет Chrome считать своим регионом США для экспериментов:
   - добавляет `--variations-override-country=us --lang=en-US` в ярлыки Chrome: на рабочем столе, в меню «Пуск», на панели задач и в общие ярлыки для всех пользователей (для них нужны права администратора, Windows спросит через UAC). Если в ярлыке уже был `--lang=` или `--variations-override-country=`, он заменяется;
   - добавляет те же аргументы в запись автозагрузки Chrome, если она есть;
   - добавляет их в обработчик ссылок, чтобы Chrome, открытый ссылкой из другой программы, тоже их получал;
   - записывает страну в `Local State` (`variations_permanent_overridden_country`).
5. Снова запускает Chrome и проверяет, что он работает с подменой. Если скрипт работает с правами администратора, он не запускает Chrome, потому что Chrome тоже получил бы эти права: запустите Chrome с ярлыка.

Перед любыми изменениями скрипт сохраняет исходное состояние в `%LOCALAPPDATA%\chrome-gemini-unlock\backup`: файлы копируются туда, значения реестра записываются в `manifest.txt`. Повторные запуски эту копию не перезаписывают. По ней `-Restore` откатывает изменения; после полного отката папка переименовывается в `backup-restored-<дата>`, и следующий запуск сохранит состояние, каким оно будет тогда.

## Требования

- Windows 10 или 11 с Windows PowerShell 5.1 (встроен в систему). Если запустить скрипт из PowerShell 7, он сам перезапустится в Windows PowerShell 5.1.
- Google Chrome, стабильная версия, хотя бы раз запущенный под вашей учётной записью Windows. Beta, Dev и Canary не поддерживаются.

## Как пользоваться

1. Скачайте `chrome-gemini-unlock-vX.Y.Z.zip` из [последнего релиза](https://github.com/Artem2603/chrome-gemini-unlock/releases/latest) и распакуйте архив. (**Code → Download ZIP** даёт текущую версию в разработке.)
2. Дважды щёлкните `chrome-gemini-unlock.bat`.
3. Если Chrome запущен, скрипт спросит, закрыть ли его: введите **Y** (или **Д**) и нажмите Enter. Любой другой ответ отменяет запуск, и ничего не меняется.
4. Если Windows попросит права администратора, подтвердите. Они нужны только для общих ярлыков; если отказаться, всё остальное всё равно сработает.
5. Chrome перезапустится. На панели инструментов должна появиться кнопка Gemini.

Параметры можно добавить, если запускать скрипт из командной строки в папке с распакованными файлами, например:

```bat
chrome-gemini-unlock.bat -NoAdmin
```

| Параметр | Что делает |
|---|---|
| `-Country us` | Регион для экспериментов, две буквы. По умолчанию `us`. |
| `-Agent` | Включить ещё и агентские функции (см. «Что важно знать»). Без него агентские флаги возвращаются в Default. |
| `-Force` | Закрыть Chrome, не спрашивая. Нужен в неинтерактивном сеансе, где скрипт не может задать вопрос. |
| `-Restore` | Откатить изменения по резервной копии (см. «Откат»). |
| `-NoAdmin` | Никогда не запрашивать права администратора; общие ярлыки не меняются. |
| `-NoLaunch` | Не запускать Chrome в конце. |

Повторный запуск безопасен: уже настроенные ярлыки и обработчики ссылок скрипт отмечает как «уже настроен», запись автозагрузки, в которой аргументы уже есть, не меняется, а резервная копия хранит состояние до первого запуска. При этом каждый запуск всё равно закрывает и перезапускает Chrome и заново записывает флаги и языковые настройки.

**Проверка скачанного файла.** У каждого релиза рядом с ZIP лежит файл `.sha256`. В PowerShell, в папке с обоими файлами, эта команда должна вывести `True`; иначе это не тот ZIP, который был опубликован:

```powershell
(Get-FileHash .\chrome-gemini-unlock-v1.0.0.zip -Algorithm SHA256).Hash -eq (Get-Content .\chrome-gemini-unlock-v1.0.0.zip.sha256).Split(' ')[0]
```

Замените `v1.0.0` на скачанную версию.

## Что важно знать

- **Запускайте Chrome с ярлыков.** Если какая-то программа запускает `chrome.exe` напрямую, этот Chrome стартует без подмены из командной строки. Страна, записанная в `Local State`, тогда действует только на часть экспериментов.
- **Проверка подмены:** откройте `chrome://version`. В строке «Command Line» должно быть `--variations-override-country=us`.
- **Автозагрузка.** Chrome сам управляет своей записью автозагрузки и может пересоздать её без подмены. Если Gemini пропал после перезагрузки, выключите «Continue running background apps when Google Chrome is closed» в `chrome://settings/system` или запустите скрипт ещё раз.
- **Обновления Chrome** могут пересоздать общие ярлыки. Если Gemini пропал после обновления, запустите скрипт ещё раз.
- **Общий компьютер.** Общие ярлыки действуют для всех учётных записей Windows на компьютере. Чтобы изменить только свои ярлыки, запустите скрипт с `-NoAdmin`. Chrome в сеансах других пользователей Windows скрипт никогда не закрывает; Chrome, запущенный «от имени другого пользователя» на вашем же рабочем столе, закрывается как ваш.
- **Языки и синхронизация.** Языки профилей становятся `en-US,en`, поэтому сайты будут открываться на английском, если у них есть такая версия. При включённой синхронизации Chrome список языков попадёт и в ваш Chrome на других компьютерах.
- **Обработчик ссылок.** Скрипт кладёт личную копию регистрации ссылок Chrome в `HKCU\Software\Classes` (`ChromeHTML`, `ChromePDF`). Если удалите Chrome, удалите и эти разделы (см. «Откат»).
- **Агентские функции** по умолчанию выключены. С `-Agent` Gemini может нажимать, вводить текст и заполнять формы за вас в вашем браузере, где вы вошли в свои аккаунты. Веб-страница может спрятать в своём содержимом инструкции для ИИ (prompt injection) и заставить Gemini действовать против вас. Включайте их, только если принимаете этот риск, и следите за тем, что делает Gemini.
- **Срок действия флагов.** По метаданным флагов Chromium срок большинства этих флагов истекает после Chrome 160; у `glic-actor` — после Chrome 172, у `enable-browser-actuator-for-glic-experimental-triggering` и `glic-actor-script-tools` — после Chrome 170. После этого Chrome игнорирует флаг, если Google не продлит его срок. Скрипт предупреждает, если установленный Chrome новее версии, после которой истекает срок флага. Срок `glic-actor-cursor` истёк уже в Chrome 155, а продлили его до 160 только с Chrome 156: в Chrome 155 скрипт предупреждает. Chrome при каждом запуске удаляет настройку истёкшего флага, поэтому чтобы временно вернуть его, включите `chrome://flags/#temporary-unexpire-flags-m154`, перезапустите Chrome и снова запустите скрипт.
- **Копия для администратора.** Для общих ярлыков скрипт записывает свою копию в папку резервных копий и запускает её с правами администратора. Перед запуском копия проверяется по SHA-256: если какая-то программа изменила её, пока был открыт запрос Windows, копия не запускается и общие ярлыки не меняются. Перед каждой записью в папку резервных копий скрипт проверяет, нет ли там точки соединения или символической ссылки, и через них не пишет.

## Откат

Выполните в командной строке в папке с распакованными файлами:

```bat
chrome-gemini-unlock.bat -Restore
```

Как и при обычном запуске, скрипт спрашивает, прежде чем закрыть Chrome, и в конце снова его запускает. По резервной копии он возвращает только то, что изменил сам:

- флаги Glic (остальные флаги остаются как есть);
- язык интерфейса и языки тех профилей, которые скрипт менял;
- сохранённую страну;
- аргументы ярлыков Chrome (значок, закрепление и имя остаются такими, как сейчас);
- запись автозагрузки, если она ещё существует;
- обработчик ссылок: личная копия удаляется или заново импортируется раздел, который существовал до скрипта;
- ярлыки Chrome, получившие аргументы без резервной копии, например закреп на панели задач, сделанный с изменённого ярлыка, теряют эти два аргумента.

Всё остальное, что Chrome записал после первого запуска, например другие настройки или новые профили, остаётся. Для общих ярлыков снова нужны права администратора: подтвердите запрос Windows, иначе они не изменятся; тогда скрипт сообщит, что откат неполный, сохранит резервную копию, и `-Restore` можно запустить ещё раз. После полного отката папка резервных копий переименовывается в `backup-restored-<дата>`: следующий `-Restore` уже не вернёт состояние до самого первого запуска.

**Ручной откат** (если скрипт запустить не получается):

1. В Chrome: `chrome://flags` → **Reset all** (или верните в Default по одному флаги `glic` и `enable-browser-actuator-for-glic-experimental-triggering`), затем выберите свои языки и язык интерфейса в `chrome://settings/languages`.
2. Уберите `--variations-override-country=us --lang=en-US` из поля «Объект» в свойствах каждого ярлыка Chrome. Если в ярлыке раньше был свой `--lang=`, верните его; исходный ярлык лежит в резервной копии (`shortcuts\<код>\<имя>.lnk`).
3. Откройте `%LOCALAPPDATA%\chrome-gemini-unlock\backup\manifest.txt` и удалите разделы реестра, которые в нём помечены как `created`:
   ```bat
   reg delete "HKCU\Software\Classes\ChromeHTML" /f
   reg delete "HKCU\Software\Classes\ChromePDF" /f
   ```
   Если в копиях есть `registry\handler-*.reg`, вместо этого дважды щёлкните его: он восстановит раздел, который существовал до скрипта.
4. Если в манифесте есть строка `...\Run  GoogleChromeAutoLaunch_<код> = ...`, удалите это значение автозагрузки; Chrome сам создаст его снова, когда понадобится:
   ```bat
   reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v GoogleChromeAutoLaunch_<код> /f
   ```
5. Закройте Chrome полностью: закройте все окна, а если в области уведомлений есть значок Chrome, щёлкните его правой кнопкой и выберите **Exit** («Выход»). Проверьте в диспетчере задач (вкладка «Подробности»), что не осталось ни одного `chrome.exe`, иначе Chrome запишет свои настройки поверх изменений. Затем удалите сохранённую страну из `Local State` через PowerShell:
   ```powershell
   $f = "$env:LOCALAPPDATA\Google\Chrome\User Data\Local State"
   [IO.File]::WriteAllText($f, ([IO.File]::ReadAllText($f) -replace ',"variations_permanent_overridden_country":"[a-z]*"', ''))
   ```

## Файлы

| Файл | Назначение |
|---|---|
| `chrome-gemini-unlock.bat` | Запуск двойным щелчком: вызывает PowerShell-скрипт и передаёт ему параметры. |
| `chrome-gemini-unlock.ps1` | Сам скрипт. Сообщения на английском, русском, французском и немецком, язык выбирается по языку Windows. |
| `tests/` | Модульные тесты, проверка флагов в настоящем Chrome и сквозной тест на Windows. |
| `.github/workflows/test.yml` | Запускает тесты в GitHub Actions. |
| `.github/workflows/release.yml` | По тегу вида `v1.2.3` запускает все тесты и, если они прошли, публикует релиз. |
| `tools/build-release.sh` | Собирает релиз: ZIP, его SHA-256 и заметки к выпуску. |
| `CHANGELOG.md` | Что изменилось в каждой версии. |

Проверено на Windows 11 с Chrome 154. `tests/chrome-flags.ps1` запускает настоящий Chrome и проверяет, что он применяет каждый флаг, кроме тех, что по таблице сроков скрипта в этой версии уже истекли (в Chrome 155 — все, кроме `glic-actor-cursor`).
